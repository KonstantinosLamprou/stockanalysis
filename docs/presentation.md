# Gliederung der Präsentation

Zeigt,dass ihr versteht
    was ihr berechnet
    warum ihres berechnet
Verständlichkeit wichtiger als Komplexität
    klare Struktur
    aussagekräftige Grafiken
    Einordnung der Ergebnisse

Daten verstehen → Modell → Training → Prognose → Bewertung
Fokus auf Modellierung und Einordnung der Ergebnisse

Die Frage die ich mir stellen sollte, was genau sollte meine Präsentation vorzeigen: 
Ich möchte vorzeigen, wie ich mehrere ausgewählte Modelle auf einer Aktie trainiert habe. 
Sie dann mit dem Baseline Modell oder einer Regel verglichen habe. 
Und so bestimmt habe, was denn genau eigentlich das beste Modell ist. 
Genau das sollte meine Präsentation klar machen. 

0. Aufgabenvorstellung
1. Daten verstehen 
2. Eine Baseline vorstellen
3. Modelle im Blick (Modellvorstellung)
4. Warum diese Modelle
5. Training Fokus
6. Prognose
7. Modellvergleich
8. Fazit
